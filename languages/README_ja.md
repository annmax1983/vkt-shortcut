# vkt-shortcut — ショートカットキー管理ツール
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

キーボードショートカットをブロック・リマップできる軽量ブラウザ拡張です。誤操作を防ぎ、キーの動きを自由にカスタマイズして、キーボードを完全にコントロールしましょう。

> Chromium ベース · Manifest V3 · トラッキングなし · ルールは 100% ローカル保存

---

## 主な違い

| 競合ツールの課題 | vkt-shortcut の解決策 |
|---|---|
| ❌ ブロックのみでリマップ不可 | ✅ キーのブロックに対応。リマップはプレミアムで解放 |
| ❌ ルールが分散し一元管理できない | ✅ デフォルトですべてのサイトに適用。サイト単位の絞り込みも可能で、グローバルスイッチ付き |
| ❌ キー入力構文が複雑 | ✅ キーを押すだけで自動認識 |
| ❌ データ送信とプライバシーリスク | ✅ 設定はすべてブラウザ内にローカル保存 |
| ❌ 無料版の機能制限が厳しい | ✅ ブロック・プリセット・入出力はすべて無料、ルール数も無制限 |

---

## 機能

### 🆓 無料版

| 機能 | 説明 |
|---|---|
| ショートカットのブロック | ウェブページ内のキーボードショートカットをサイト別に無効化 |
| キー入力 | 目的のキーを押すだけで自動記録 |
| 適用範囲 | デフォルトは全サイト。特定サイト（サブドメイン含む）に限定することも可能 |
| サイトプリセット | 人気サイトで報告されている競合をワンクリックでブロック — YouTube（K/J/L/M/F/C/I/T）、X（N/L/R/T/B/M, /）、Reddit（A/Z 投票・J/K/C/S）、Facebook（J/K/L/C/S, /）、GitHub（S/T/W/B/X）、豆包の Ctrl+J、Notion の Ctrl+P/J、VS Code Web の Ctrl+P/J。対応サイトはパネルに一覧表示されるため、事前にそのサイトを開く必要はありません。プリセットのキーは 1 つにつき 1 ルールとして追加されます |
| すべてのショートカットをブロック | サイトごとのスイッチでページ側ショートカットをすべて無効化。パネル上部には全サイト一括のグローバルスイッチもあり（文字入力・方向キーでの移動・クリップボード・再読み込みはそのまま。サイトごとの一時停止が優先） |
| グローバルスイッチ | すべてのルールをワンクリックで有効/無効化 |
| ルール数 | 上限なし（有効・無効を問いません） |

### ⭐ プレミアム（ライセンスで解放）

| 機能 | 説明 |
|---|---|
| **キーのリマップ** | キー A をキー B の操作に置き換え |
| **デバイス間同期** | ログイン中のブラウザアカウント経由でルールを同期（当社サーバーは介在しません） |
| **優先サポート** | 優先的なサポート |

## 利用シーン

- **Web アプリ** — Google Docs や Office 365 で F1 ヘルプの誤起動をブロック
- **ブラウザゲーム** — ゲームの妨げになるサイト側ショートカットを無効化（注：Ctrl+W や F11 などブラウザ予約キーはページに届かないため、ページ単位のブロックでは妨害できません。`chrome.commands` を使う拡張機能でも、空のコマンドに割り当てて一部を無効化できるだけです）
- **開発者ツール** — DevTools のショートカットをリマップして IDE との競合を回避
- **アクセシビリティ** — 複雑な組み合わせを簡単なキーに置き換え
- **プレゼンテーション** — 発表中はナビゲーション以外のページ内ショートカットをブロック

## プライバシー

- ✅ ルールがブラウザの外に出ることはありません — ブロックもリマップも完全にローカルで処理
- ✅ アナリティクス・トラッキング・クッキーなし
- ✅ ルールは `chrome.storage.local` のみに保存
- ✅ 必要な権限は `storage` + `sidePanel` のみ
- ℹ️ 唯一の通信はライセンスの認証・検証（任意）で、ライセンスキー・ランダムなインストール識別子・ブラウザ情報をライセンスサーバー（`api.annmax1983.com`）へ送信します
