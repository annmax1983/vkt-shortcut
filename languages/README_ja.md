# vkt-shortcut — ショートカットキー管理ツール
[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

キーボードショートカットをブロック・リマップできる軽量ブラウザ拡張です。誤操作を防ぎ、キーの動きを自由にカスタマイズして、キーボードを完全にコントロールしましょう。

> Chromium ベース · Manifest V3 · トラッキングなし · ルールは 100% ローカル保存

---

## 主な違い

| 競合ツールの課題 | vkt-shortcut の解決策 |
|---|---|
| ❌ ブロックのみでリマップ不可 | ✅ キーのブロックに対応。リマップはプレミアムで解放 |
| ❌ ルールが分散し一元管理できない | ✅ デフォルトですべてのサイトに適用。サイト単位の絞り込みも可能で、グローバルスイッチ付き |
| ❌ キー入力構文が複雑 | ✅ キーを押すだけで自動認識 |
| ❌ データ送信とプライバシーリスク | ✅ 設定はすべてブラウザ内にローカル保存 |
| ❌ 無料版の機能制限が厳しい | ✅ 無料で 3 件のルール。軽い用途には十分 |

---

## 機能

### 🆓 無料版

| 機能 | 説明 |
|---|---|
| ショートカットのブロック | 任意のサイトでキーボードショートカットを無効化 |
| キー入力 | 目的のキーを押すだけで自動記録 |
| 適用範囲 | デフォルトは全サイト。特定サイト（サブドメイン含む）に限定することも可能 |
| グローバルスイッチ | すべてのルールをワンクリックで有効/無効化 |
| 最大 3 件のルール | 無料版では 3 件まで登録可能 |

### ⭐ プレミアム（ライセンスで解放）

| 機能 | 説明 |
|---|---|
| **ルール数無制限** | ルール数の上限なし |
| **キーのリマップ** | キー A をキー B の操作に置き換え |
| **インポート/エクスポート** | JSON でルールをバックアップ・復元 |
| **優先サポート** | ライセンスユーザーは迅速な対応 |

## 利用シーン

- **Web アプリ** — Google Docs や Office 365 で F1 ヘルプの誤起動をブロック
- **ブラウザゲーム** — ゲームの妨げになるサイト側ショートカットを無効化（注：Ctrl+W や F11 などブラウザ予約キーはどの拡張機能でも妨害できません）
- **開発者ツール** — DevTools のショートカットをリマップして IDE との競合を回避
- **アクセシビリティ** — 複雑な組み合わせを簡単なキーに置き換え
- **プレゼンテーション** — 発表中はナビゲーション以外のショートカットをブロック

## インストール方法

1. Chrome Web Store の vkt-shortcut ページを開く
2. **Chrome に追加**をクリックして確認
3. ツールバーの ⌨️ アイコンをクリックしてサイドパネルを開く

---

## プライバシー

- ✅ ルールがブラウザの外に出ることはありません — ブロックもリマップも完全にローカルで処理
- ✅ アナリティクス・トラッキング・クッキーなし
- ✅ ルールは `chrome.storage.local` のみに保存
- ✅ 必要な権限は `storage` + `sidePanel` のみ
- ℹ️ 唯一の通信はライセンスの認証・検証（任意）で、デバイス情報のみをライセンスサーバー（`api.annmax1983.com`）へ送信します
